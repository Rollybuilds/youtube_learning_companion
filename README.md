# 📚 YouTube Learning Companion

AI-powered study tool that turns video transcripts into notes and quizzes.

**Live app:** https://youtubelearningcompanion-4akfkp22jpzuytrkmabcmf.streamlit.app/

## Problem
Students who learn from long YouTube lectures spend hours rewatching confusing parts, with no quick way to revise or test what they understood.

## Solution
Paste a transcript and get a summary, key points, and a 5-question quiz in seconds.

## Built with
Python, Streamlit, Google Gemini API

## Status
Version 1 is live. Next: structured notes, quiz difficulty, flashcards, and Ask the Transcript.
